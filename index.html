Backup and moving between devices

Progress is saved in this browser. To carry it to another device, export a backup here and import it there. Import merges: it adds the other device's ticks, cards and log entries to yours and never wipes anything. Newer changes win, so an item you un-ticked stays un-ticked.

Sync with a private GitHub gist (optional)

Keeps your phone and PC in step automatically, with no server of ours. Your progress is saved in one secret gist on your own GitHub account. Each device pulls and merges when the app opens, and pushes a few seconds after you change something.

What you need: a GitHub token that can only touch gists. It works like a password for that one job, and is stored only in this browser. It isn't in your backups and isn't sent anywhere except GitHub.

  1. On GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens and press Generate new token (open the page).
  2. Give it a name like "Data Skills sync" and an expiry date. Under Repository access choose Public repositories (it doesn't need any). Under Account permissions, set Gists to Read and write. Leave everything else as "No access".
  3. Generate it, copy it, and paste it below. Do the same on your other device (you can reuse the token).

A classic token also works if you tick only the gist scope.

Turning sync off deletes the token from this browser. Your progress here stays. The gist stays on GitHub until you delete it at gist.github.com, and you can revoke the token in GitHub's settings at any time.
